# 快译模式第二阶段上线

此版复用用户提供的 FastMode v1.5.1 离线识别核心。页面不依赖 Node、本机 8799 端口、两个 ps1 文件或模型服务。只发布离线规则；参考项目的后台密钥、运行数据和模型知识文档不发布。

1. 由管理员手动执行 upgrade_quick_bet_full.sql（如果首次部署，须先执行 upgrade_quick_bet.sql 建表）。本脚本建立一套共用的34行玩法赔率，并全部设为启用；“具体和值”14项已下线，不再由本脚本写入。脚本会覆盖已有共用赔率和开关，但保留已有共用玩法说明。后续人工调整或停用后不要重复执行。开发和本地测试均不连接 MySQL。
   如果此前执行过按彩种分别配置的旧版 full 脚本，仍需手动执行本版脚本以建立共用配置；旧行保留作历史数据，但不会再被读取。
   已上线过48项配置的站点，发布新版代码后可由管理员手动执行 retire_quick_bet_concrete_sum.sql 删除“具体和值”14条共用赔率行；不需要重跑 upgrade_quick_bet_full.sql，且历史投注与审计记录不会删除。
2. 发布 PHP、HTML 与 public/assets/lottery/quickref/ 下的静态脚本。不要发布参考目录的 .module-runtime、server.mjs、settings.json 或 ps1。
3. 后台只显示一套共用赔率、玩法说明和启停；修改一处对福彩3D、排列三均生效，但两彩种仍分别投注和开奖。旧的按彩种配置行会保留在数据库中，不再读取或编辑。codex.txt 是历史需求文本，其部分赔率与 FastMode v1.5.1 当前默认值不同；本脚本以 FastMode 当前参考页面为准。本站后台赔率为唯一权威值。
4. 前台识别全部使用参考模块离线规则；候选若含后台未启用的玩法、错误彩种或待补充段落，整批不可投注。确认时会刷新赔率；投注接口再次验证玩法、赔率版本、期号、单注金额与余额，并保存赔率快照。开奖按保存快照计算。
5. 参考页的“确认生成”仅在本机保存候选；本站“确认投注”会真实扣款、生成订单与新代理体系返水。识别记忆只在真实投注成功后保存于当前浏览器的当前账号和彩种下，换设备不自动同步。
6. 快译页的彩种固定为当前所在页面。参考原文若明确标注另一彩种，会阻止下单，不能悄悄转投另一彩种。
7. 先运行不连接数据库的 php tests/quick_bet/quick_bet_service.php 与 node tests/quick_bet/quick_bet_parity.mjs，再在测试环境用小额验证：样例 518 581 185 一百直10组 应产生 6 笔、合计 330 元；其中直选 3 笔各 100 元，三码组选六 3 笔各 10 元。虽然默认全部启用，仍应先在测试环境核对投注、开奖、撤单、返水与 PC/手机展示，再发布到生产环境。
