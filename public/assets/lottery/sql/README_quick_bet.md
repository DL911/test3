# 快译模式首批上线说明

1. 管理员手动执行 `upgrade_quick_bet.sql`。此脚本只新增快译配置、配置日志、注单审计表及后台菜单；所有玩法默认停用。
2. 发布代码后，在后台“快译玩法赔率”核对两个彩种的赔率与说明，再逐项启用。没有启用的玩法无法下单。
3. PC、手机投注页在“双面盘 / 标准盘”旁进入快译模式。当前首批支持：三码直选、一码定位、两码定位、和值大小单双、指定单个位置大小单双。
4. 文字识别接受清晰的单行单笔格式，如 `直选 123 10元`、`百位 5 10元`、`百十 56 10元`、`和值单 10元`、`百位大 10元`；也支持标题为“直选”或“两码定位”、中间多行号码、末尾“各打20元”的整段格式。其余写法进入待补充，允许手动添加支持的玩法后核对。整批未核对完不能提交。
5. 参考模块中的任意一码、组三/组六组合及全包、豹子全包、和值具体数字与多号码展开等尚未映射到本站完全相同的结算规则，不能在首批真实投注中启用。后台不能添加任意玩法代码，只能维护已实现的玩法。
6. 快译使用独立的后端下注接口，一次提交形成一张含多笔明细的正式订单；下注、扣款、返水和审计在同一事务中。开奖调用快译专用中奖判定并使用投注时保存的赔率快照。撤单复用本站原有的订单撤单与返水冲正。
7. 赔率变动会改变配置版本，未提交注单需重新核对。重复请求使用客户端操作标识和数据库唯一键避免重复扣款。

当前 SQL 由管理员手动执行；开发与静态验证不连接 MySQL。
